= API Security Scanners
ifndef::env-site,env-github[]
include::_attributes.adoc[]
endif::[]

API security scanners connect external API security platforms to Anypoint Platform. Instead of importing services, they correlate security findings, risk scores, and incidents from the external platform with APIs and MCP servers that already exist in Exchange.

These are the supported API security scanners:

* xref:adding-akamai-api-security-scanner.adoc[Akamai API Security]

== Before You Begin Adding a Scanner

Make sure you have the permission and access:

* Exchange Administrator permission
* Verify that you are in the business group where you want to add the scanner.
