You can now use an MCP server endpoint to retrieve Agent Fabric asset and instance metadata from Exchange for your assets in Exchange, including Agents and MCP servers. The endpoint uses the Exchange API to search for and return this metadata.

== Using the MCP Server Endpoint

Use this endpoint to configure an MCP server connection in your AI client: `https://anypoint.mulesoft.com/exchange/mcp`

You must authenticate to access private Exchange assets. Configure your AI client to use your Anypoint Platform credentials when connecting to the endpoint.


After you connect your AI client to the MCP server endpoint, you can perform these tasks:

* *Search for assets* – Search by asset name, description, or keywords to find agents, MCP servers, large language models (LLMs), and other assets in Exchange.
* *Retrieve asset metadata* – Get metadata for an asset, including available versions, dependencies, instances, and documentation so you can evaluate and use the asset in your projects.
* *Query user profile and permissions* – Check your user profile and permissions so you know what you can access, publish, or manage in Exchange. For maximum security control, assign the Exchange permissions your agents need. See xref:to-set-permissions.adoc[].

You can perform other actions, including reading reviews and ratings for an asset on the platform.
