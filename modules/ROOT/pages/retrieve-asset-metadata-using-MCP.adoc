If you don't have Flex Gateway deployed, use the Exchange MCP server endpoint to get asset and instance metadata from Exchange for your AI agents. The MCP server endpoint uses the Exchange API to search and retrieve this metadata programmatically.

== Using the MCP Server Endpoint

Use this endpoint when configuring an MCP server connection in your AI client: `https://anypoint.mulesoft.com/exchange/mcp`

You must authenticate to access private Exchange assets. Configure your AI client to use your Anypoint Platform credentials when connecting to the endpoint.

== What You Can Do

After you connect your AI client to the Exchange MCP server, you can perform these tasks:

* *Search for assets* – Search by asset name, description, or keywords to find agents, MCP servers, large language models (LLMs), and other assets in Exchange.
* *Retrieve asset metadata* – Get metadata for an asset, including available versions, dependencies, and documentation so you can evaluate and use the asset in your projects.
* *Access reviews and ratings* – Read reviews and ratings for assets to compare options and choose the right asset for your use case.
* *Query user profile and permissions* – Check your user profile and permissions so you know what you can access, publish, or manage in Exchange.
