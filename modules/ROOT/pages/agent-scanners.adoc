= Agent Scanners
ifndef::env-site,env-github[]
include::_attributes.adoc[]
endif::[]

Agent scanners connect external agent platforms to Anypoint Platform. They discover, import, and catalog agents into Exchange so you can govern them and use them from other applications.

Supported agent scanners:

* xref:adding-amazon-bedrock-scanner.adoc[Amazon Bedrock]
* xref:adding-bedrock-agentcore-scanner.adoc[Amazon Bedrock AgentCore]
* xref:adding-google-vertex-scanner.adoc[Google Vertex AI]
* xref:adding-microsoft-copilot-scanner.adoc[Microsoft Azure Copilot]
* xref:adding-microsoft-foundry-scanner.adoc[Microsoft Foundry]
* xref:adding-godaddy-scanner.adoc[GoDaddy ANS]

== Before You Begin Adding a Scanner

Make sure you have the permission and access:

* Exchange Administrator permission
* Verify that you are in the business group where you want to add the scanner.
