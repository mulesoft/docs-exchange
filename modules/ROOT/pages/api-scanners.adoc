= API Scanners
ifndef::env-site,env-github[]
include::_attributes.adoc[]
endif::[]

API scanners connect external API gateways to Anypoint Platform. They discover, catalog, and sync APIs from third‑party platforms into Exchange, apply governance rulesets across gateways, optionally front external endpoints with Flex Gateway, and support guided migrations to bring external APIs under Anypoint management. 

These are the supported API gateway scanners:

* xref:adding-amazon-gateway-scanner.adoc[Amazon API Gateway]
* xref:adding-azure-api-management-scanner.adoc[Azure API Management]
* xref:adding-kong-gateway-scanner.adoc[Kong API Gateway]
* xref:adding-apigee-scanner.adoc[Google Apigee API Gateway]

== Before You Begin Adding a Scanner

Make sure you have the permission and access:

* Exchange Administrator permission 
* Verify that you are in the business group where you want to add the scanner.
