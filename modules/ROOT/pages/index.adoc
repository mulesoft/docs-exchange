Anypoint Exchange is a curated catalog of reusable assets. See xref:asset-types.adoc[Asset Types] for more information about each type of asset that's supported. You can catalog (publish), share, discover, learn about, and reuse assets within your organization of developers to facilitate collaboration, boost productivity, and promote standards.

image:exchange-landing-page.png["Exchange catalog showing assets provided by MuleSoft"]

Use Exchange to discover, share, and incorporate assets and resources into your applications, and view asset usage and engagement metrics. You can create developer portals, view and test APIs, simulate sending data to APIs by using the mocking service, and create assets.

Exchange assets are accessible from many places, such as Anypoint Studio (connectors, templates, and examples), API Manager (APIs, API groups, and policies), or Runtime Manager (applications). You can publish assets from agent network projects such as agents, brokers, and MCP servers, as well as APIs from Anypoint Code Builder and Design Center to Exchange.

== MuleSoft Assets
Assets in the *Provided by MuleSoft* organization are created by MuleSoft and its partners and certified by MuleSoft. These assets are publicly available to all customers. 

Exchange automatically discovers, translates, and publishes publicly hosted MCP servers from the https://registry.modelcontextprotocol.io/[official MCP registry] into *Provided by MuleSoft*. Exchange labels these assets as *Publicly Available*. Find the assets using the *provider-managed* tag. These assets are maintained by their original providers, not by MuleSoft. When you create an instance from publicly available assets, the instance is created within your private organization in Exchange and managed like any other instance in API Manager. You can also request access to running instances from publicly available assets.
 
However, assets that are created by an organization other than *Provided by MuleSoft* and published in that organization's instance of Exchange are private and not visible outside that organization. Customers are responsible for any private assets they publish within their Exchange instance.

== Agent Fabric Assets
MuleSoft Agent Fabric is an enterprise platform for discovering, orchestrating, governing, and observing AI agents and tools. It serves as a central control plane and registry for agent assets in Anypoint Exchange. For more information, see xref:agent-fabric::index.adoc[Agent Fabric].

The Agent Fabric registry contains AI assets, such as agents and tools. Find agent, LLM, and MCP server assets in the *Agents & Tools (New)* tab. 

image:ex-agents-and-tools.png["Exchange catalog showing assets in Agents & Tools"]

AI assets are added to the registry via these methods:

* xref:to-create-an-asset.adoc[Registering them manually].
+
Manually create and publish assets directly in Exchange.
* xref:discovering-and-importing-external-agents.adoc[Importing agents using scanners].
+
Discover and import agents from external providers into Exchange using scanners.
* xref:importing-agentforce-agents.adoc[Importing Agentforce agents from Settings]
+
Import Agentforce agents from Salesforce into Exchange from Settings.

* xref:anypoint-code-builder::af-agent-networks.adoc[Creating agent network projects in Anypoint Code Builder and publishing them to Exchange].
+
Use Anypoint Code Builder to create agent network projects that define, validate, and publish brokers, agents, large language models (LLMs), and MCP servers. Anypoint Code Builder publishes agent network projects and their associated assets to the agent registry in Exchange with a *Broker* label.

== View Assets by Business Group

A system administrator groups individuals within an organization into business groups. Each group has its own Exchange assets. 

To view the business groups, log in to Anypoint Platform and click a group name from the taskbar:

image::ex2-biz-groups.png["List of business groups"]

An Exchange administrator sets the groups that this menu displays for each user.

If you can't find an asset in the current business group scopes, search in other scopes. In the navigation menu, click *All assets* (assets provided by MuleSoft and your own root organization), *Provided by MuleSoft*, or a business group scope.

== Get Started

You can get started either by searching for an existing asset or creating a new one.

. From https://anypoint.mulesoft.com/exchange/[Exchange], either search by type of assets or enter the name of a known asset in the *Search assets* field.
. Select an asset from the search results view.
. Review the description of the asset.

To create assets, log into Exchange, then see xref:workflow-sharing-assets.adoc[Workflow: Publish Assets] for more information.

== Test APIs

You can test APIs using the mocking service.

. Click the *All Types* filter, select the REST APIs option, and click *Apply*.
. Click the asset and notice how the API functions appear in the left
navigation bar. 
. Click a function and more information appears. At the right side of the screen, you can test the API by entering sample values to send to the API and get responses from the API.

== Language Support

Using multiple languages with Unicode is supported fully throughout Exchange and in all metadata fields, including asset names, descriptions, markdown pages, categories, tags, and reviews.

* xref:usage-and-engagement-metrics.adoc[Usage and engagement metrics] aren't supported.
* Amazon CloudFront isn't configured on control planes.
