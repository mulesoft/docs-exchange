Data scanners connect external data catalog platforms to Anypoint Platform. They discover, import, and catalog data services into Exchange so you can govern them and use them from other applications.

Supported data scanners:

* xref:adding-informatica-scanner.adoc[]

== Before you begin adding a scanner

Make sure you have the permission and access:

* Exchange Administrator permission
* Verify that you are in the business group where you want to add the scanner.
