= Using the Agentic Endpoint to Retrieve Asset and Instance Information

include::_attributes.adoc[]

:imagesdir: ../assets/images/

Use the agentic endpoint to get asset and instance metadata without Flex Gateway. This endpoint uses the Exchange API to programmatically search for and retrieve metadata for any assets published to Exchange.


To configure the endpoint:
//Should the jar file be downloaded first? What's in the jar?
. Create a Mule application on Runtime Manager. 
. Deploy a Mule application to CloudHub 2.0.
. Create the client key and client secret for the application.
. Create a connected app in Access Management with Exchange Viewer permission.
. Update the Mule application in Runtime Manager by adding exchange client ID and Exchange client secret.
. Test the endpoint by verifying the assets are in the catalog on Exchange.
