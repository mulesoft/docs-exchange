= Managing Asset Deletion

:imagesdir: ../assets/images/

Control how assets are deleted in Exchange from *Settings*. Admins can choose how asset owners can delete asset versions in Exchange. They can enable or disable the ability to permanently delete an asset to reuse the GAV (group ID, asset ID, and version) for a new asset. It doesn't matter when the asset version was created. When enabled, asset owners see an option to allow the GAV to be reused when deleting an asset version. When disabled, the GAV can't be reused after deleting the asset version.

To enable or disable the option to delete an asset and reuse the GAV:

. From the navigation bar, select *Settings* and select *Asset Deletion & Connected App Management*.
. In *Asset Deletion Configuration*, enable or disable the option.
